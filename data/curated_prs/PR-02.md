- **Title:** DF.__setitem__ creates extension column when given extension scalar
- **Author:** justinessert
- **Status:** Merged

## Description
Fixes Issue #34832: `df['a'] = pd.Period('2020-01')` was creating an object column instead of a `period[M]` column. Modifies `__setitem__` and DataFrame constructor casting logic to recognize extension scalar types.
