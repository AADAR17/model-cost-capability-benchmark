## Description
Refactors VS Code's Voice Mode UI: migrates 23 signal instances from `@preact/signals-core` to VS Code's native observable system (`observableValue`), replaces `lit-html` templates with imperative DOM construction across 8 component files, decouples the glow animation from the reactive system (fixing 60fps performance thrashing), and removes 14 files of vendored library code. Resolves issue #321142.
