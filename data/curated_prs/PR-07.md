## Description
Fixes CVE-2026-35193: RFC 9111-qualified cache-control directives (e.g. `Cache-Control: private="Set-Cookie"`) were being missed after a prior change moved from substring matching to exact token matching — allowing improperly cached responses in shared caches.

## Diff
- **django/middleware/cache.py**: removed `split_header_value` import, added `split_directive_names`; cache-control parsing changed to use `split_directive_names()` with set intersection
- **django/middleware/http.py**: same import swap; `needs_etag()` updated to use the new parsing function
- **django/utils/cache.py**: `dictitem()` now strips whitespace: `return (t[0].strip().lower(), t[1])`
- **django/utils/http.py**: new `split_directive_names()` function — yields lowercased directive names, discarding qualified values per RFC 9111
- **tests/cache/tests.py**: added `test_patch_cache_control_whitespace_around_equals()`, `test_qualified_cache_control_value_not_cached()`, `test_authorization_header_exception_qualified_public_directive()`
- **tests/middleware/tests.py**: added `test_no_etag_no_store_qualified()`
