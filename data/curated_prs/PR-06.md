## Description
Refactors `TimedeltaIndex.__new__` and related scalar/datetime64 handling; changes some scalar-input errors from `ValueError` to `TypeError`; deprecates constructing a TimedeltaIndex from datetime64-dtyped data.

## Diff (summarized — large multi-file refactor; see fidelity note)
- **doc/source/whatsnew/v0.24.0.txt**: notes on the ValueError→TypeError change and the datetime64 deprecation
- **pandas/core/arrays/datetimes.py**: simplified frequency inference logic
- **pandas/core/arrays/timedeltas.py**: new `sequence_to_td64ns()`, `ints_to_td64ns()`, `objects_to_td64ns()` helpers; deprecation warning added
- **pandas/core/indexes/datetimes.py**: scalar validation moved earlier; error type changed
- **pandas/core/indexes/timedeltas.py**: `__new__` refactored to use `sequence_to_td64ns()`; duplicate return logic removed
- **6 test files** updated across timedelta/datetime construction, arithmetic, and ops tests
