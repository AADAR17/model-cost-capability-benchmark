## Description
Fixes inconsistent naming behavior in `Index.union()` and `Index.intersection()` (issues GH9943, GH9862) — ensures result index names are computed correctly across index types.

## Diff (summarized — large multi-file refactor; see fidelity note)
- **pandas/core/indexes/base.py**: import `get_op_result_name`; rename `_get_consensus_name()` → `_get_reconciled_name_object()`; replace `_wrap_union_result()` with `_wrap_setop_result()`; update `union()`/`intersection()`/`_wrap_joined_index()`
- **Index subclasses** (DatetimeIndex, TimedeltaIndex, PeriodIndex, etc.): same rename, inline name logic replaced with `get_op_result_name()` calls
- **pandas/core/indexes/range.py**: fix `_shallow_copy()` to respect name param; edge-case handling in `union()`/`intersection()`; `__getitem__()` validation updated
- **Tests**: RangeIndex added to conftest fixtures; a duplicated test updated to skip RangeIndex
