## Description
This pull request fixes an OverflowError that occurred when using `to_json()` with numbers larger than `sys.maxsize`. The solution implements a new `JT_BIGNUM` type in the ujson encoder to handle large integers without raising exceptions. Tests were added along with performance benchmarks.
