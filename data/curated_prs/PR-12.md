- **Author:** vitahlin

## Description
Fixes accounting bugs in Redis's bit manipulation commands: improper histogram tracking when existing strings grow via SETBIT/BITFIELD, and missing dirty-tracking when BITFIELD with overflow handling pads a string but rejects the write.
