## Description
Introduces two new meta-estimators: `TunedThresholdClassifierCV` (finds the optimal decision threshold for a binary classifier via cross-validation, maximizing a chosen metric) and `FixedThresholdClassifier` (lets a user set a fixed threshold without tuning). Addresses long-standing feature requests (#8614, #10117).
