## Description
Fixes a bug where commands queuing replacement operations via `alsoPropagate()` ignored selective propagation restrictions set by Lua's `redis.set_repl()` or module `RM_Call()`. Replaces a boolean `replication_allowed` flag with a bitmask (`allowed_propagate_targets`) tracking which propagation targets (AOF and/or replicas) are currently allowed, so queued effect commands respect these restrictions through nested command execution.
