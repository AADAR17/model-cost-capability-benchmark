## Description
Adds native categorical feature support to `DecisionTreeClassifier`/`Regressor` (binary classification, single-output regression), avoiding the need for one-hot encoding. Up to 256 categories per feature, via bitset-based splitting logic in the Cython tree-building internals (`_partitioner.pyx`, `_splitter.pyx`, `_tree.pyx`). Forest classes currently disable it pending RandomSplitter support (TODO comments).
